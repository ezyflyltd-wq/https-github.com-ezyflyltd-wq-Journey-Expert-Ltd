## 1. Real-Time Operations Dispatch Board
The Operations Board provides destination management teams with a real-time command dashboard for monitoring daily arrivals, transfer departures, guided tour executions, driver statuses, and emergency ground escalations.

---

## 2. Dispatch Workflow
```
+-------------------------------------------------------------------+
|               Daily Arrivals & Transfers Dashboard                |
|  (Flight Number, ETA, Passenger Name, Hotel Destination, Vehicle) |
+-------------------------------------------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|                   Driver & Vehicle Assignment                     |
|    (Assigns Driver ID, Vehicle License, Flight Delay Tracking)    |
+-------------------------------------------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|                       Status Tracking Board                       |
|   [ UNASSIGNED ] -> [ ASSIGNED ] -> [ EN_ROUTE ] -> [ PICKED_UP ] |
|                       -> [ COMPLETED ]                            |
+-------------------------------------------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|             Voucher Settlement & Operator Sign-off                |
+-------------------------------------------------------------------+
```

---

## 3. Operations Features
- **Flight Delay Compensation**: Syncs with live flight radar APIs to automatically delay driver pickup times if an incoming flight is delayed.
- **Incident Escalation Hotline**: Instant communication channel connecting local ground coordinators with JEL 24/7 central customer support.
