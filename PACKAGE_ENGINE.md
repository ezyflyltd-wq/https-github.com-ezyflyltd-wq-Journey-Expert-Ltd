## 1. Modular Package Architecture
The Package Engine allows operations staff to assemble flexible or fixed-departure packages combining flight inventory, Makkah/Madinah hotel room blocks, ground transport, and guided Ziyarat tours:

```
+-------------------------------------------------------------------+
|                        Core Package Shell                         |
|   (Title, Target Audience, Duration, Departure City, Base Cost)    |
+-------------------------------------------------------------------+
                                  |
                                  +-----------------------+
                                  |                       |
                                  v                       v
+-----------------------------------+   +-----------------------------------+
|      Makkah Hotel Component       |   |      Madinah Hotel Component      |
|  (Swissôtel, Fairmont, Clock Tower|   | (Dar Al Taqwa, Oberoi, Pullman)   |
+-----------------------------------+   +-----------------------------------+
                                  |                       |
                                  +-----------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|                     Flight Inventory Component                    |
|   (Saudia / Biman / Emirates Group PNR or Individual GDS Ticket)  |
+-------------------------------------------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|               Ground Transport & Ground Services                  |
|    (Haramain High-Speed Train, VIP Bus, Private GMC, Ziyarat)     |
+-------------------------------------------------------------------+
```

## 2. Package Pricing & Margin Control
- **Dynamic Costing**: Combines Supplier Costs (Hotel + Flight + Transport + Visa Fee) with JEL Service Fees and Channel Markups (B2C, B2B Agent, Corporate).
- **Commercial Shield**: Internal supplier costs are masked server-side; retail customers and agents view only authorized selling prices and commission margins.
