**Part 60 Execution • Autonomous Engineering System**

## 1. Automated Evaluation Suite
Continuously benchmarks specialist agents against golden test sets covering flight search accuracy, corporate policy compliance, RAG groundedness, tool selection correctness, and prompt injection resilience.

---

## 2. Evaluation Metrics
1. **Groundedness Score**: Percentage of factual statements in AI responses directly backed by retrieved RAG documents (Target >= 99%).
2. **Tool Selection Accuracy**: Rate of correct API tool selection given user intent (Target >= 98%).
3. **Policy Compliance Rate**: Zero tolerance for policy-violating recommendations presented without explicit warning tags (Target = 100%).
4. **Red-Teaming Resilience**: Zero leakage of system prompts, credentials, or cross-tenant data during adversarial prompt injection tests.
