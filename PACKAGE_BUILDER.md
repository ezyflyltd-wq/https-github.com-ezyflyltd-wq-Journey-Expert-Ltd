## 3. Custom Quotation & Versioning
- **Quote Versioning**: Quotes generated for corporate or custom group requests maintain version histories (`Quote v1`, `Quote v2`), validity expiry dates, and currency exchange rate snapshots.
- **Package Discount Engine**: Applies package bundle savings when combining 3+ components (e.g. Flight + Hotel + Tour = 5% Bundle Discount).
