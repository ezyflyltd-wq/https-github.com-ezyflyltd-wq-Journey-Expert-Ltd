## 3. Compliance Declarations
- **GDPR & Privacy Compliance**: Supports user consent management, right-to-be-forgotten data deletion workflows, and restricted data retention schedules.
- **PCI-DSS Tokenization**: All card payments process through PCI-DSS Level 1 certified gateways (Stripe, SSLCommerz). Raw credit card numbers or CVVs are never stored on JEL servers.
- **Audit Logging**: Every API invocation, financial journal entry, user login, AI prompt, and tool execution is recorded in tamper-evident audit logs.
